# 归档内容

这里保留早期探索和历史备份，不属于当前运行主流程。

- `experiments/analyze_hppc_25c.py`：仅用恢复段拟合 2RC 的早期诊断，曾出现负 R0 和不可分辨时间常数。
- `results/hppc_relaxation_25c/`：上述探索的原始输出，保留用于追溯，不能作为模型最终参数。
- `experiments/plot_c20_overview.py`：早期 C/20 概览图。
- `experiments/plot_c20_voltage_soc.py`：历史文件名虽然含 SOC，但内容实际查看电压、电流和 Ah；当前 SOC/OCV 入口是 `experiments/calibrate_ocv_25c.py`。
- `results/c20_exploration/`：两份旧 C/20 概览图。
- `backups/`：以前保存的读取模块和 README 备份。

当前代码、结果和使用方式以项目根目录 README 为准。
